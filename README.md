# Skeletal System Visual Application

## Overview

This project aims to create a visual application to display the human skeleton's bones so the user can easily visualize their structure, access their information, and see the relationships between bones. Through the combinations of the disciplines of 3D sculpting, programming, and game development, this application strives to create a user-friendly way to visualize the skeletal system's bones in a simple and accessible form. To that end, there is Windows and Web Page support, covering resource heavy and light configurations respectively.

* All 3D models were created from scratch by co-author

## Tech Stack

- Unity
- Blender
- Visual Studio

## Features

- Includes all the bones of the upper body
- Access to summarized bone's information
- Ability to visualize bones from various angles
- Support for English and Spanish (only on 'Filter Scene' currently)
